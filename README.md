# CineBook

A responsive movie-ticket booking UI built with React, TypeScript and Vite.

## Features

- Movie discovery and search
- Genre filters
- Movie details
- Theatre and showtime selection
- Interactive seat map
- Live ticket total
- Booking confirmation
- Responsive dark cinematic design
- No backend required for the demo

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Push this repository to GitHub, then import the repository in Vercel. Vercel will detect Vite automatically.

No environment variables are required for the demo.
